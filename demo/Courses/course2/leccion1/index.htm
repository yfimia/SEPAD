Lección 1: Etiquetas básicas de HTML

Toda página HTML tiene la misma estructura:

<html>
  <head>
    <title>Mi primera página</title>
  </head>
  <body bgcolor="#FFFFFF">
    <h1>Hola, mundo</h1>
    <p>Este es un <b>párrafo</b>.</p>
  </body>
</html>

Etiquetas frecuentes: <b> negrita, <i> cursiva, <a href> enlace, <img src> imagen y <font> tipo de letra.
