Lección 3: Correo electrónico

Una dirección de correo tiene la forma usuario@dominio. El correo viaja de servidor en servidor usando el protocolo SMTP y se descarga con POP3.

Normas de cortesía (netiquette):

  1. Escriba un asunto claro.
  2. No escriba todo en MAYÚSCULAS: equivale a gritar.
  3. Evite adjuntar archivos muy grandes si el destinatario tiene una conexión lenta.

SEPAD también permite estudiar por correo electrónico, pensado para quienes no tienen conexión permanente.
