Lección 2: El World Wide Web

El World Wide Web fue propuesto por Tim Berners-Lee en el CERN en 1989. Se basa en tres ideas:

  • HTML: el lenguaje con que se escriben las páginas.
  • URL: la dirección única de cada recurso, por ejemplo http://www.ejemplo.edu/index.htm.
  • HTTP: el protocolo con que el navegador pide las páginas al servidor.

Para navegar se usa un navegador como Netscape Navigator o Internet Explorer. Cuando la conexión es lenta conviene desactivar la carga automática de imágenes.

Consejo: guarde en Favoritos las direcciones que visite a menudo.
